# Cleaner Discord Theme
A Discord theme to make the desktop UI look way cleaner
This theme uses css snipits from various different creators, all are credited inline within the css.

# Installation
Install [Vencord](https://github.com/Vendicated/Vencord) or another discord client mod that allows you to install themes / change css.
<br>
Paste the following in your QuickCSS editor:
```
@import url("https://epos05.github.io/cleaner-discord-theme/theme.css");
```
